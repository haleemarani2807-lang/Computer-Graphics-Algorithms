# Computer Graphics Algorithms

This repository contains implementations of basic Computer Graphics algorithms using Python.

## Algorithms Implemented

### 1. DDA Line Drawing Algorithm
DDA (Digital Differential Analyzer) is an incremental line drawing algorithm used to generate points between two endpoints of a line.

### 2. Bresenham's Line Drawing Algorithm
Bresenham's algorithm is an efficient line drawing algorithm that uses integer calculations to determine the pixels required to represent a line.

### 3. Midpoint Circle Drawing Algorithm
The Midpoint Circle algorithm is used to draw a circle efficiently by calculating points for one portion of the circle and using symmetry to obtain the remaining points.
